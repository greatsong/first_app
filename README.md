# 범용 바이브 코딩 웹앱 실습

GitHub Pages에 배포하는 정적 웹앱에서 시작해 Google Sheets, Open API, DB 연동까지 단계적으로 확장하는 왕초보용 프로젝트 템플릿입니다.

## 바로 보기

GitHub Pages 배포 주소:

https://greatsong.github.io/first_app/

## 목표

- GitHub Pages로 웹앱을 직접 배포한다.
- HTML, CSS, JavaScript 파일의 역할을 구분한다.
- AI에게 기능을 요청하고, 결과를 검토하고, 작게 수정하는 바이브 코딩 흐름을 익힌다.
- Google Sheets를 간단한 데이터 저장소처럼 읽어 온다.
- 공개 Open API를 `fetch()`로 호출한다.
- Supabase 같은 DB 서비스와 연동하는 기본 구조를 이해한다.

## 챕터

1. GitHub Pages 배포
2. 바이브 코딩 기본 흐름
3. Google Sheets 읽기
4. Open API 호출
5. DB 연동
6. 최종 프로젝트 조립
